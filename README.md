# pulsegen

VLM-assisted quality assurance for bounding-box annotation datasets: given annotated images, decide whether each object's label is correct and its box is properly sized, and propose verified corrections for human review.

Pre-implementation design: [docs/architecture/vlm-annotation-qa-design.md](docs/architecture/vlm-annotation-qa-design.md) (fact-check ledger: [docs/architecture/fact-check-ledger.json](docs/architecture/fact-check-ledger.json)).
